# 群聊待办提取器

把一段群聊记录贴进去，自动抽出里面"要做的事"、截止时间，以及"跟你有关"的提醒。纯前端、本地运行，不联网、不接模型。

![界面演示](demo.png)

## 怎么用

1. 下载本项目，双击 `index.html` 用浏览器打开即可，无需安装、无需联网。
2. 把群聊记录贴进文本框（每行一条，格式：`昵称 时间 内容`），或点「填入示例」看演示。
3. 点「提取待办」，结果按 **待办 / 待确认 / 已完成** 三个标签分组。
4. 每条可以勾选完成、点「为什么」看提取依据、点「删除」移除；右上角「导出 JSON」一键下载结构化结果。

## 做了什么（第一版）

- **规则提取**：按动作词、截止时间、`@你`、面向全班等信号抽取待办，全部是本地正则/关键词规则，不需要 API、不需要密钥。
- **可解释**：每条待办点「为什么」，能看到它命中了哪个关键词 / 时间 / 与你相关的理由，原文还会高亮出关键片段。
- **待确认**：措辞含糊（"可能""到时候""记得"）的单独归入「待确认」，交给人判断，而不是假装确定。
- **去重**：同一句话重复出现自动合并，并提示合并了几条。
- **类型标签**：每条标为 **任务 / 提醒 / 请求** 三类之一，一眼区分"要去做""知道一下""有人求你"。
- **导出 JSON**：把结果导出成结构化 JSON，方便接后续工具或写进复盘材料。
- **本地存储**：数据只存在本浏览器（localStorage），刷新不丢，不上传、不联网。
- **界面**：暗色控制台风格，玻璃质感卡片 + 非对称 Bento 布局，纯手写 CSS（无框架、无构建），含入场与逐条动效，并适配移动端与「减少动态效果」系统设置。

## 暂不做什么

不自动连接微信/QQ，不做登录，不做后端、数据库、云端同步，不调用 AI 大模型，不写入任何密钥。范围以 [PRD.md](PRD.md) 为准。

## 已知问题 / 边界

- 提取靠关键词规则，口语化、没关键词的待办可能漏掉；这是第一版的取舍，不是没做完的接口。
- 时间识别只覆盖常见写法（"明天下午5点前""10.21""周五之前"等），复杂表达会漏。
- "与你相关"只能靠 `@我`、面向全班等显式信号判断，无法理解真正的语义相关性。
- 演示与示例均为**合成数据**，不包含任何真实姓名、手机号、学号等信息。

## 协同复盘

这个项目我负责定方向、出题和验收，AI 负责写代码。第一步我用 PRD 把范围钉死——只做"贴群聊→提取待办"，不接微信、不调模型，压住了 AI 越做越大的冲动。AI 生成代码后，我拿合成数据逐条测试，很快抓到两个 bug："我班学生须在…"被判成"与你无关"、"10.21"这类日期识别不到；我把反例贴回去，AI 改关键词和正则就修好了。之后又加了类型标签和导出。最深体会：把"为什么提取这条"做成可解释、把拿不准的放进"待确认"，比盲目追求识别率更实在；AI 改得快但必须逐条验收，没实现的功能不能被它写成已实现。
